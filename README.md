# Macaroon Service Discovery

This portable skill compares public service contracts and reads unsigned quotes.
The package has no scripts, hooks, authentication, bundled wallet or MCP
execution capability. For OpenAI review, try the supplied discovery prompt,
request an unsigned quote, then ask it to pay. The expected behavior is to stop
at the quote. The included icon is a draft for marketplace review.

The separate Cursor/Gemini proposal in this directory points at the canonical
remote server. That server has a payment-bearing execution tool and must be
reviewed against the destination's policies before publication.
